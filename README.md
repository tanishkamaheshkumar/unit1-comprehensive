# Unit 1 Comprehensive Git Exercise

This repository demonstrates an end-to-end Git and GitHub workflow.

## Objectives

- Configure Git
- Create and manage a local repository
- Create commits
- Use selective staging
- Work with branches
- Merge branches
- Resolve merge conflicts
- Push a repository to GitHub
- Use GitHub Issues and Pull Requests
- Understand `git fetch` and `git pull`

## Technologies Used

- Git
- GitHub
- Markdown
